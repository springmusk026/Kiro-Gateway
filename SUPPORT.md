# Getting help

1. **Check the documentation** — [installation](docs/installation.md), [connecting clients](docs/clients.md),
   [configuration](docs/configuration.md) and especially [troubleshooting](docs/troubleshooting.md) answer most
   questions.
2. **Search existing issues** — someone may have had the same problem:
   [open and closed issues](https://github.com/springmusk026/Kiro-Gateway/issues?q=is%3Aissue).
3. **Open an issue** — use the bug report or feature request form. Include your version, how you run the
   gateway, the client you use and relevant log lines (with keys, tokens and emails removed).

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening an issue.

Kiro Gateway is maintained in spare time; responses may take a few days. Kiro account, billing and service
questions should go to Kiro's own support.
